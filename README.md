# Research OS

เว็บแอปหน้าเดียว (ไฟล์ `index.html` ไฟล์เดียว) ช่วยงานวิจัยของงานอายุรกรรมทั่วไป โรงพยาบาลจุฬาภรณ์
ผู้พัฒนา: ดร.พญ.กมลทิพย์ เลิศชัยสถาพร

- ไม่มี backend ไม่เรียก API/AI ภายนอก ข้อมูลเก็บใน localStorage ของเบราว์เซอร์ (Export/Import JSON ได้)
- โมดูล: PICO/FINER, บอร์ดโครงการ, reporting guideline checklist, ขนาดตัวอย่าง, AI-use integrity
- ข้อมูลที่เห็นครั้งแรกเป็น "ตัวอย่าง" เท่านั้น ห้ามกรอกข้อมูลที่ระบุตัวผู้ป่วย
